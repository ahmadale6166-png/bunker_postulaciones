## 🛠️ Infraestructura y Tecnologías
- **Entorno:** Termux (Android 15) con automatización en Nushell y Bash.
- **Redes y Conectividad:** Cloudflare Tunnels (`cloudflared`), Proxy SOCKS5 (Tor), SSH (`ed25519`).
- **Bases de Datos:** MariaDB, PostgreSQL, SQLite.
- **Lenguajes:** Python 3, Java, JavaScript (Node.js).
